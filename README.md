Personal Portfolio Website

Features

- Responsive Design: Designed to work across desktop, tablet, and mobile devices.
- About Section: A personal introduction with a profile picture.
- Experience Section: Highlights my projects and technical experience.
- Projects Showcase: Displays selected projects with images and descriptions.
- Mobile Navigation: Interactive navigation menu for smaller screens.
- Social Media Icons: Quick access to social profiles.
- Contact Section: Includes an email input interface.

Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome Icons
